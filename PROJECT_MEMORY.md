## 3. Анатомия компонентов и Физика движения (Fluid Standards)

1. **Органический контур карточек (Deckle Edge / Clay Cutout):**
   - Реализация через адаптивный CSS SVG `clip-path` и маску волнообразного контура, предотвращающая артефакты пикселизации и обеспечивающая Zero-CLS.
   - Эластичная физика пружин (`damping: 1.0`).
2. **Нулевая задержка нажатия (Zero-Latency Press):**
   - На всех интерактивных элементах (кнопки плеера, треки, ссылки соцсетей):
   - `:active { transform: scale(0.97); transition-duration: 40ms; }` на событие `pointerdown`.
3. **Интерактивный Game Audio Player:**
   - Деморил (видео/аудио) с покадровой синхронизацией и кастомными контроллерами (Play/Pause, Seek ±15s, Scrubbing, Timecode, Volume).
   - Поддержка мультитрекового переключения стемов (Full Mix / Ambience / SFX / Lead Synth) — ключевая фича для портфолио игрового композитора.
4. **Безопасность мобильного скролла:**
   - `overflow-x: clip;` для предотвращения залипания кинетического скролла в мобильных браузерах.

## 5. Кинематика и микроанимации (WebTactics Animation Suite)

1. **Fluid Magnetic Cursor:**
   - Двойное кольцо (`#cursor-dot` 6px + `#cursor-ring` 36px) с интерполяцией Lerp (`0.22`).
   - Наведение на кликабельные элементы расширяет кольцо до 58px и переключает цвет.
   - Автоматически отключается на тач-устройствах (`@media (pointer: coarse)`).
2. **3D Tilt & Specular Dynamic Sheen (Физика глиняных карточек):**
   - Интерактивное отслеживание координат курсора над `.deckle-card-wrapper` с расчетом дельты `±3.8deg` (`--tilt-x`, `--tilt-y`).
   - Динамический радиальный блик (`--sheen-x`, `--sheen-y`, `--sheen-opacity`), скользящий по поверхности бумаги.
3. **WWDC Magnetic Pull on Buttons:**
   - Кнопки плавно притягиваются к курсору в радиусе наведения (`translate3d(dx * 0.22, dy * 0.22, 0)`).
4. **Бесконечный вертикальный контр-скролл боковых рельсов (Zero-Gap Counter-Marquee):**
   - Боковые ленты `SPIRALEYE` движутся непрерывно во встречных направлениях: левая сторона поднимается вверх, правая сторона спускается вниз.
   - Контейнеры `.side-rail` зафиксированы на `align-items: flex-start` (вместо центрирования), что исключает смещение точки отсчета при цикле анимации.
   - Двойной сегмент текста по 7 слов ($H_{seg} \approx 2310\text{px}$, суммарная высота $4625\text{px}$) с циклом 28s гарантирует 100% перекрытие экрана даже на 4K/2160p мониторах в любой момент времени (зазор = 0px).
   - Анимация работает на GPU-потоке композитора браузера через CSS `@keyframes` с `will-change: transform`, гарантируя 60/120 FPS без просадок при любом скролле или нагрузке на CPU.
5. **In-View Kinetic Reveals:**
   - Плавное появление секций из глубины (`translateY(32px) scale(0.985)`) с линией-вайпом под заголовками секций.
6. **Audio-Reactive Breathing:**
   - В реальном времени считывает энергию низких частот из `AudioContext Analyser` и модулирует легкое «дыхание» плеера (`--audio-scale`).

## 7. Архитектура плейлиста, стемов и кастомных обложек (v1.2.0)

### Структура конфигурации (`js/playlist.js`):
Файл `js/playlist.js` содержит массив `PLAYLIST` со всеми треками, их обложками и режимами воспроизведения:
1. **Режим стемов (`hasStems: true`):**
   - Указываются 4 дорожки в объекте `stems: { ambient, melody, foley, bass }`.
   - В интерфейсе активны все 4 кнопки MUTE на пульте стемов.
   - Пользователь может изолировать или отключать любую дорожку на лету.
2. **Режим стерео-мастера (`hasStems: false`):**
   - Указывается один файл в поле `audioUrl: 'path/to/master_mix.mp3'`.
   - Пульт стемов автоматически отображает информационную плашку `Stereo Master Mix Mode`, а кнопки мьюта стемов деликатно приглушаются (`opacity: 0.4`, `disabled`).
3. **Обложки к трекам:**
   - Поле `cover: 'assets/covers/<track-name>.jpg'`.
   - При смене трека (через кнопки Prev/Next, клик по плейлисту или карточкам проектов) обложка плавно обновляется:
     - В главном окне показа (`#showreel-poster`).
     - В плавающем нижнем доке (`#dock-cover-thumb`).
     - В списке треков плейлиста (`.playlist-item.is-active`).

### Упрощение анимаций:
- Убраны анимации появления блоков при скролле (`reveal-on-scroll`) и 3D-наклон карточек (`tilt`), устраняя лишний визуальный шум и исключая сдвиги макета (Zero-CLS).
- Магнитное прилипание (`setupMagneticButtons`) сохранено исключительно для кнопок в хедере и плавающем нижнем доке / футере.
- Бесконечный счетчик-скролл на боковых рельсах (`SPIRALEYE`) сохранен в неизменном виде.

## 8. Локальная визуальная консоль композитора — Spiraleye Studio Admin (v1.3.0)

### Запуск:
```bash
npm run admin
```
Сервер автоматически открывает браузер по адресу `http://localhost:3001/admin` с флагом `--start-maximized`.

### Возможности админки:
1. **Интерактивный треклист:**
   - Превью обложек, длительность, жанр, статус (Stems vs Stereo).
   - Быстрая смена порядка треков (стрелки ▲ / ▼) со мгновенной перезаписью конфигурации.
2. **Визуальный редактор трека:**
   - **Загрузка обложек (Drag & Drop):** сохранение в `assets/covers/` с автоматической генерацией читаемого имени.
   - **Выбор аудио-режима:**
     - *4-Channel Stems:* 4 слота для перетаскивания файлов (*Ambient*, *Melody*, *Foley*, *Bass*) с индивидуальными аудиоплеерами для предпрослушивания.
     - *Stereo Master Mix:* 1 слот для мастер-трека.
   - **Авто-детекция длительности:** через браузерный `AudioContext.decodeAudioData(buffer)` с автоматическим заполнением секунд (`duration`) и формата `M:SS` (`durationFormatted`).
3. **Безопасность и валидация:**
   - Создание локальной резервной копии `js/playlist.js.bak` перед каждой записью.
   - Форматирование чистого семантического JavaScript кода конфигурации.
4. **Синхронизация с GitHub в 1 клик:**
   - Модальное окно прямо в интерфейсе админки.
   - Автоматически выполняет `git add`, `git commit` и `git push origin main` с выводом терминального лога.
